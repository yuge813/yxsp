# 红金版实现说明

核心业务：签到赚金币、自愿看激励广告、金币兑换、商品试用、邀请好友。五个主入口为首页、赚金币、好礼、试用、我的。

页面使用重新编排的原生 WXML/WXSS。红色主视觉、金色票券、礼盒与金币插画、图标及统一状态组件均为本地资源。正式商品、库存、价格、余额、二维码和试用结果由原后台提供；演示照片和数据只供隔离的浏览器预览使用。

已确认的48张设计包含页面及页内状态，不等于48个新路由。原项目48个注册路由保留兼容，历史阅读、成长与已关闭内容页不占据核心入口。对应关系见 `RED_SCREEN_COVERAGE.md`。

## 状态与业务边界

- 签到成功、真实签到记录、提醒及帮助保留原接口。
- 广告使用微信原生激励视频。前置页、到账、提前关闭、核验中和冷却状态独立展示；奖励到账只认真实服务端账本。原home/read结算通道保留。
- 商品展示、余额不足、售罄、兑换确认与回执使用真实数据；提交期间加锁，网络不确定时先核对订单。物流仅展示实际承运商与单号，不生成虚假轨迹。
- 试用申请成功与中选结果分开。结果仅采用实际状态字段；未知状态不推断为未中选。
- 邀请海报使用已核验专属二维码，通过原生Canvas导出；分享使用微信原生能力，不虚构好友选择器或邀请奖励。
- 钱包未知余额显示未知；失败保留最近成功数据。地址选择先暂存，再由用户明确使用。

## 验证

78项离线行为测试、48页模块及模板引用检查通过。14个实际代码浏览器预览使用隔离演示数据，390px无横向溢出。尚未执行微信编译、真机、实际后端和原生SDK联调；具体边界见项目README及ACCEPTANCE.md。

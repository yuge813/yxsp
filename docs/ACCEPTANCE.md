# 微信开发者工具与真机联调

这份清单覆盖离线验证无法证明的实际行为，尚未在本轮执行。

| 场景 | 期望 |
|---|---|
| 首次进入、返回首页/我的 | 登录成功后真实余额更新；失败显示重试，不把未知当0；已读信息保留 |
| 任务直接链接进入 | 无会话或会话过期可重新连接；可参与/冷却/次数用完/预算满/核验中操作一致 |
| 签到 | 服务端控制奖励；重复点击一次请求；成功后明细和余额同步；异常不伪造成功 |
| 视频 | home/read分别使用原通道；提前关闭无奖励；完整观看需服务端确认；无广告填充后可继续正常使用 |
| 阅读 | 无需观看广告即可读；分类切换不串旧结果；搜索仅匹配已加载文章；字号/收藏/分享可用 |
| 兑换 | 真实库存/价格/余额/地址；确认前不下单；提交锁；失败能恢复；网络不确定先核对订单；服务端核验幂等 |
| 订单 | 初始/空/失败区分；返回刷新；分页重试；实际物流、确认收货与后端状态一致 |
| 试用 | 未开始、进行中、结束与未知状态区分；只有真实开放可报名；成功报名不表述为中选；资料提交后记录刷新 |
| 邀请海报 | 真实专属二维码、后台活动配置、有效海报资源；过期会话重连；无强迫分享或虚假奖励承诺 |
| 提醒与权限 | 用户主动订阅；拒绝不影响签到；头像昵称自主；原生地址权限失败可手动填写 |
| 窄屏/安全区 | iOS/Android，320/375/390/430逻辑宽，字体放大、长标题/大余额，固定按钮/底栏与广告无重叠 |
| 公告 | 实际场景、冷却、次数限制保留；长内容可滚动，主按钮及关闭可点；无效外链不打开 |
| 编译包 | 48页可编译；真实主包/分包及资源体积满足当前微信规则 |

正式环境仅使用实际后台配置，不把 `design/preview` 中的演示数据与照片 导入业务。使用现有测试站检查，确认后再由项目维护者发布。

# 阅读、成长与一级推广补充

以用户上传的“最满意版sage_dksy_wxapp.zip”为准核对，776个正式源码文件与已交付红金版完全相同；原附件不修改。继续使用已满意的红金布局和五个主导航，补齐以下功能及说明。

| 功能 | 入口 | 页面与说明 |
|---|---|---|
| 阅读文章与广告激励 | 首页、赚金币、我的 → 阅读文章 | `v12/list`、`v12/detail`；免费阅读，原生激励视频由用户自愿选择，沿用read结算通道。实际金额、次数、冷却及核验结果取后台；到账/提前关闭/处理中/失败分别表达。 |
| 7天成长礼遇 | 首页、赚金币、我的 → 7天成长礼遇 | `growth/index`；开启计划、7天进度、第3/7天礼遇、真实可领取资格、账本入口。成长进度与连续签到独立，基础签到与成长额外奖励分别结算。 |
| 一级推广 | 首页、赚金币、我的 → 一级推广 | `v11/promote`、`v132grow/index`；真实专属二维码、海报、直属一级好友及注册/归属记录、累计及今日新增。有效首次邀请归属不覆盖。只有已批准、已启用、可公开的实际活动才展示奖励。 |
| 分类说明 | 功能页规则入口，或 我的 → 帮助与活动说明 | `v14/rewards/index?category=read/growth/invite`；进入即选择对应分类，说明免费阅读、完整观看、独立成长、节点领取、一级归属、奖励到账与好友同行的区别。 |

成长首次开启保持原接口兼容：成功状态中明确尚未加入且未明确禁用时，允许用户主动开启；未知参与状态不能开启，已加入后的新一轮需明确允许。提交结果不确定时先刷新核对，避免重复提交。

一级推广沿用 `v11visit`/`v11bind` 的真实服务端凭据与首次关系；仅扫码、分享、浏览、好友的好友不计入成功一级人数。领取金额与资格不由说明文字预设。

对应实际代码浏览器预览在 [preview/benefits](preview/benefits/README.md)。离线测试与浏览器预览均不能代替微信编译、真机、真实后台及原生SDK联调；本次未发布小程序。

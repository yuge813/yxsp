# 真实一级邀请奖励交付说明

这是可记入现有金币钱包和流水的固定金币活动。旧后台的“30%参考比例”和增长预算模拟不结算本活动，已保留并澄清入口与说明。

## 实际规则

| 对象 | 真实条件 | 本次默认奖励 |
| --- | --- | --- |
| 新朋友B | 活动开始后新注册、通过有效邀请入口形成首次直属绑定，且获得参与名额；窗口内首次正常签到 | B额外5金币 |
| 直属邀请人A | 同一B在窗口内累计2个不同北京时间自然日签到，不要求连续 | A得10金币 |

默认窗口为注册日起7个北京时间自然日，含注册当日。每位B每档终身一次，金币不能提现；不增加二级收益或现金购物入口，奖励条件不包含广告观看/点击。

客户端不提交奖励金额、邀请人目标或签到次数来申请发币。服务端使用已验证身份、注册信息、真实绑定审计及签到记录。普通签到提交后独立结算邀请奖励，邀请服务失败不把普通签到改成失败；后续本人状态核验可重试，A刷新收益也可恢复已达标但漏结算的直属B记录。

## 钱包与预算

- 确认参与时先预留A+B共15金币，再显示资格；达标转为已发放，未达标到期才释放余额。
- 每日预算按确认参与的北京时间日期记承诺，包含已发及预留，与旧人民币模拟预算分开。
- 活动暂停和结束只停止新增参与，已确认参与保留原金额、条件、窗口和预算。后续规则改动只影响新参与者。
- 余额、金币流水、奖励唯一记录、预算转移同一事务；写入失败回滚。数据库读取失败不能当作0天签到而清除资格。
- 邀请归属变更不会把原A奖励转移给新上级；历史到账不改写。原有广告、兑换及试用渠道保持各自规则。

390px 和 320px 两种视口的七种状态均已检查：页面和文档没有横向溢出，奖励卡片、标签、明细和签到到账票券没有溢出，WXML 表达式转换警告为零。几何结果保存在 `geometry.json` 和 `geometry-320.json`。邀请页的实际收益及活动金额已移到邀请票券下方，奖励记录页的重复跳转明细按钮已移除。

图片中的好友、金额、日期和状态均为独立布局演示。此检查覆盖浏览器布局和可读性，不等同于微信编译器、微信原生渲染、真机或正式后台发放验证。复现方法见 [预览工具说明](../../../design/preview/README.md)。
